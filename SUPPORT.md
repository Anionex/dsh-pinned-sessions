# Support

Use the repository's issue forms so reports include the information needed to act on them:

- [Bug report](https://github.com/Anionex/dsh-pinned-sessions/issues/new?template=bug.yml) for broken or regressed behavior.
- [Feature request](https://github.com/Anionex/dsh-pinned-sessions/issues/new?template=feature.yml) for a concrete workflow improvement.
- [Usage question](https://github.com/Anionex/dsh-pinned-sessions/issues/new?template=question.yml) for installation or compatibility help.

Before filing, update to the latest plugin release and check existing issues. Include the DSH version and profile. Remove API keys, tokens, private conversation text, local usernames, and sensitive paths from screenshots and logs.

Follow [SECURITY.md](SECURITY.md) for vulnerabilities. Public issues are not a private reporting channel.
